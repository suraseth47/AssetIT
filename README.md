# ระบบทะเบียนอุปกรณ์ไอที (IT Device Registry)

เว็บแอปสำหรับบันทึกและค้นหาข้อมูลอุปกรณ์ไอทีขององค์กร (โน้ตบุ๊ก จอ เครื่องพิมพ์ สวิตช์ กล้องวงจรปิด) แทนไฟล์ Excel ที่เคยส่งต่อกันทางอีเมล
ทำงานทั้งหมดในเบราว์เซอร์โดยไม่ต้องมีเซิร์ฟเวอร์หรือฐานข้อมูล

## ภาพหน้าจอ

## ฟีเจอร์ที่ทำได้แล้ว

- เพิ่มอุปกรณ์ใหม่ พร้อมสร้างรหัสครุภัณฑ์ (assetId) ให้อัตโนมัติ
- แก้ไขข้อมูลอุปกรณ์ที่มีอยู่ (ชื่ออุปกรณ์ ประเภท หมายเลขเครื่อง ผู้ถือครอง สถานะ)
- ลบอุปกรณ์ออกจากรายการ พร้อมกล่องยืนยันก่อนลบทุกครั้ง
- ค้นหาอุปกรณ์แบบพิมพ์แล้วกรองผลทันที (ไม่ต้องกดปุ่ม) จากชื่ออุปกรณ์ หมายเลขเครื่อง หรือผู้ถือครอง โดยไม่สนใจตัวพิมพ์เล็ก-ใหญ่
- กรองรายการตามประเภทอุปกรณ์และตามสถานะ
- แสดงจำนวนรายการที่พบเทียบกับจำนวนทั้งหมด เช่น "พบ 5 จาก 12 รายการ"
- บันทึกข้อมูลอัตโนมัติลง localStorage ของเบราว์เซอร์ ปิด-เปิดใหม่ข้อมูลยังอยู่

## วิธีใช้งาน

1. Clone หรือดาวน์โหลดโปรเจกต์นี้ลงเครื่อง
2. เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ (แนะนำ Chrome หรือ Edge เวอร์ชันล่าสุด) ใช้งานได้ทันทีโดยไม่ต้องติดตั้งหรือ build อะไรเพิ่ม
3. กรอกฟอร์ม "เพิ่มอุปกรณ์ใหม่" แล้วกดบันทึก เพื่อเพิ่มข้อมูลอุปกรณ์เข้าไปในรายการ
4. ใช้ช่องค้นหาหรือตัวกรองด้านบนตารางเพื่อหาอุปกรณ์ และใช้ปุ่ม "แก้ไข"/"ลบ" ท้ายแต่ละแถวเพื่อจัดการข้อมูล

## เทคโนโลยีที่ใช้

- HTML / CSS / JavaScript ล้วน ไม่มี framework หรือไลบรารีภายนอก
- Web Storage API (localStorage) สำหรับเก็บข้อมูลถาวรในเบราว์เซอร์ ไม่มี backend หรือฐานข้อมูล

## ข้อจำกัดที่ผู้ใช้ควรรู้

- **ข้อมูลเก็บอยู่ในเบราว์เซอร์เครื่องเดียวเท่านั้น** อยู่ที่ localStorage ของเบราว์เซอร์ที่ใช้งาน หากล้างแคช เปลี่ยนเบราว์เซอร์ หรือเปลี่ยนเครื่อง ข้อมูลจะไม่ติดตามไปด้วยและอาจสูญหาย ปัจจุบันยังไม่มีฟีเจอร์ export/import สำรองข้อมูล
- ไม่มีระบบล็อกอินหรือแยกสิทธิ์ผู้ใช้ ใครก็ตามที่เปิดเบราว์เซอร์เครื่องนี้ได้จะแก้ไขหรือลบข้อมูลได้ทั้งหมด
- ไม่รองรับการใช้งานพร้อมกันหลายคนหรือหลายเครื่อง เพราะข้อมูลไม่ได้ซิงก์ผ่านเซิร์ฟเวอร์กลาง
- ลบอุปกรณ์แล้วกู้คืนไม่ได้ และไม่มีการเก็บประวัติการแก้ไขค่าก่อนหน้า
- ดูรายละเอียดข้อกำหนดและขอบเขตทั้งหมดของโปรเจกต์ได้ที่ [SPEC.md](./SPEC.md)

## หมายเหตุ

โปรเจกต์นี้จัดทำขึ้นเป็นผลงานระหว่างการอบรม เป็นเวอร์ชันต้นแบบ (MVP) ที่พัฒนาโดยผู้พัฒนาคนเดียวภายในเวลาจำกัด ฟีเจอร์ที่ระบุไว้ใน SPEC.md บางส่วนยังไม่ได้พัฒนาในรอบนี้
