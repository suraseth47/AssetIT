# ระบบทะเบียนอุปกรณ์ไอที (IT Device Registry)

เว็บแอปสำหรับบันทึกและค้นหาข้อมูลอุปกรณ์ไอทีขององค์กร (โน้ตบุ๊ก จอ เครื่องพิมพ์ สวิตช์ กล้องวงจรปิด) แทนไฟล์ Excel ที่เคยส่งต่อกันทางอีเมล ช่วยแก้ปัญหาหาข้อมูลไม่เจอ ไม่รู้ว่าเครื่องไหนอยู่กับใคร และมีหลายเวอร์ชันจนไม่รู้ว่าอันไหนล่าสุด ทำงานได้ทั้งหมดในเบราว์เซอร์โดยไม่ต้องมีเซิร์ฟเวอร์หรือฐานข้อมูล

## ฟีเจอร์

- เพิ่ม แก้ไข ลบ และดูรายการอุปกรณ์ พร้อมบันทึกอัตโนมัติในเบราว์เซอร์
- ค้นหาและกรองอุปกรณ์ด้วยชื่อ รหัสครุภัณฑ์ ผู้ถือครอง ประเภท หรือสถานะ
- นำเข้าข้อมูลจากไฟล์ CSV เพื่อรวมไฟล์ Excel หลายเวอร์ชันเข้าเป็นชุดเดียว
- Export/Import ข้อมูลทั้งหมดเป็นไฟล์ JSON สำหรับสำรองข้อมูล
- สร้างและพิมพ์ QR code ต่ออุปกรณ์ ทั้งแบบทีละใบและพิมพ์เป็นชุด
- สแกน QR code ผ่านกล้องเว็บแคมเพื่อเปิดข้อมูลอุปกรณ์ทันที
- แดชบอร์ดสรุปจำนวนอุปกรณ์ตามประเภทและสถานะ
- ไฮไลต์สีอัตโนมัติเมื่ออุปกรณ์ใกล้หมดประกันหรือยังไม่ระบุผู้ถือครอง
- แนบรูปถ่ายอุปกรณ์ได้

## วิธีเปิดใช้งาน

1. Clone หรือดาวน์โหลดโปรเจกต์นี้ลงเครื่อง
2. เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ (แนะนำ Chrome หรือ Edge เวอร์ชันล่าสุด)
   - หมายเหตุ: ฟีเจอร์สแกน QR ผ่านกล้องต้องเปิดผ่าน `http://` หรือ `https://` ไม่ใช่ `file://` เนื่องจากข้อจำกัดด้านความปลอดภัยของเบราว์เซอร์ แนะนำให้รันเซิร์ฟเวอร์ static เบาๆ เช่น `npx serve .` หรือใช้ส่วนขยาย Live Server ของ VS Code
3. ใช้งานได้ทันที ไม่ต้องติดตั้ง dependency หรือ build ใดๆ เพิ่มเติม
4. ข้อมูลจะถูกบันทึกอัตโนมัติใน localStorage ของเบราว์เซอร์นั้น แนะนำให้กด "Export ข้อมูล" เพื่อสำรองไฟล์ JSON เป็นระยะ

## เทคโนโลยีที่ใช้

- HTML / CSS / JavaScript (ไม่มี backend หรือเซิร์ฟเวอร์)
- Web Storage API (localStorage) สำหรับเก็บข้อมูล
- qrcode.js สำหรับสร้าง QR code
- html5-qrcode สำหรับสแกน QR code ผ่านกล้อง
- PapaParse สำหรับนำเข้าไฟล์ CSV

## หมายเหตุ

โปรเจกต์นี้จัดทำขึ้นระหว่างการอบรม เป็นเวอร์ชันต้นแบบ (MVP) ที่พัฒนาโดยผู้พัฒนาคนเดียวภายในเวลาจำกัด จึงยังมีข้อจำกัดบางประการ เช่น เก็บข้อมูลเฉพาะในเบราว์เซอร์เครื่องเดียวและไม่รองรับหลายผู้ใช้พร้อมกัน ดูรายละเอียดข้อจำกัดเพิ่มเติมได้ใน [SPEC.md](./SPEC.md)
